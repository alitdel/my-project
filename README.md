
# DRUG ABUSE AWARENESS SYSTEM

Welcome — this is a small, friendly website created to share clear information, local support, and recovery resources for people and communities affected by drug use.

## Why this site

The goal is simple: make helpful, trustworthy information easy to find. The pages are written to be edited by anyone — health workers, volunteers, family members, or community groups — so they can adapt the content for local needs.

## What you'll find

- Practical prevention guides and awareness materials
- Local helplines and service listings
- Recovery tools, support ideas, and personal stories
- A short FAQ to answer common questions

## Project structure

- `index.html` — Home
- `about.html` — Who we are and why we care
- `awareness.html` — Campaigns, tips, and outreach
- `services.html` — Local and online services
- `stories.html` — Testimonies and hope
- `resources.html` — Guides, worksheets, and links
- `FAQ.html` — Frequently asked questions
- `contacts.html` — Hotlines and contact details
- `styling.css` — Central stylesheet for layout and colors
- `assets/` — Images and media

## Quick start (view locally)

Open the folder in your browser to view the site. If you prefer a quick local server, run:

```powershell
python -m http.server 8000
# then open http://localhost:8000
```

## Editing tips

- Change page copy directly in the `.html` files.
- Update colors and layout in `styling.css` for a site-wide look.
- Keep one `toggleMenu()` script per page (place just before `</body>`).
- Improve accessibility: add meaningful `alt` text for images and `title` for any embedded frames.

## Help improve this site

If you have local resources, corrections, or wording suggestions, please edit the files and share them back. Small, practical improvements make a big difference.
